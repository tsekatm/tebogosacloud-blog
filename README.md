# tebogosacloud.blog

Source for my personal tech blog — cloud architecture, DevOps, AI, and the journey to senior technical leadership.

**Live site:** [tebogosacloud.blog](https://tebogosacloud.blog)

## Stack

Built with [Astro](https://astro.build), styled with Tailwind CSS, deployed on Netlify.

## Recent Series

A 7-part series on building an evaluation framework for AI code generators (companion to [3_site_builder_agent_eval](https://github.com/tsekatm/3_site_builder_agent_eval)): [Beyond Text: How We Built an Evaluation Framework for Multi-File AI Outputs](https://dev.to/tsekatm/beyond-text-how-we-built-an-evaluation-framework-for-multi-file-ai-outputs-1d10)

## Run Locally

```bash
npm install
npm run dev
```
